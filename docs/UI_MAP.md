# Bryce 3D UI map

Observed on 2026-11-26 on MetaCreations Bryce 3D for Windows, 1920x1080 display. Positions
are UI pixels from the top-left of the 640x480 interface. The source of truth is
`src/bryce3d_mcp/layout.py`.

## Observed working

| Action | How | Result seen |
| --- | --- | --- |
| Name a control | Hover over it | Bryce shows "Create <name>" bottom-left |
| Create a cube | Click the cube on the Create palette | "Cube 1", 6 polygons, 20.48 units, origin y=10.24 |
| Open Object Attributes | The A badge, or Ctrl+Alt+E | Dialog at a fixed place, low and right |
| Enter exact values | Double-click Position X, type, press Tab, type Y | After OK and reopening: 25.50, 30. The server double-clicks every field instead of using Tab |
| Open Materials Lab | Ctrl+M | Full-size panel |
| Apply a preset | Arrow by the preview, red swatch, check, check | Cube turned red |
| Render | Large sphere at the lower left | Rendered, then Render Report |
| Open object library | Arrow beside "Create" | Categories and a 5 x 6 grid, closed with the X |
| Duplicate, select all | Ctrl+D, Ctrl+A | Object and polygon counts matched |
| Select in viewport | Press, hold about 0.3 s, release on an edge | Selected. Instant clicks on edges did not |
| Delete, undo | Delete, then Ctrl+Z | Cube removed, then restored |

The server holds the button for 0.12 s. That shorter time has not been tried on Bryce: raise
it in `win32.py` if viewport selection misses.

## Seen on screen but not exercised

- Object Attributes: name field, Neutral / Positive / Negative / Intersect, Hidden, Locked,
  the Origin, Rotate and Size inputs, and the Linking and Animation tabs.
- Object library categories: Boolean Objects, Mountains, Rocks&Trees, Paths, Imported
  Objects, Tutorial, User, with Add, Delete, Import and Export buttons.
- Material categories: Simple&Fast (used), Planes&Terrains, Rocks&Stones, Waters&Liquids,
  Clouds&Fogs, Wild&Fun, Complex fx, Miscellaneous, Glasses, Metals, Volume, Tutorial, User.
- Materials Lab: color channels, and Diffusion, Ambience, Specularity, Metallicity, Bump
  Height, Transparency, Reflection and Refraction values.
- Edit and Sky&Fog tabs, camera controls, animation timeline.

## Unverified

- Alt+F did not open a menu, and pointing at the top edge did not reveal a menu bar.
  Whether the window has a native Win32 menu is unknown, so `list_menus` may return nothing.
- Shortcuts other than those observed above come from a
  [Bryce 7 shortcut list](https://tutorialtactic.com/blog/bryce-7-shortcuts/). The ones
  that were tried on Bryce 3D (Ctrl+Alt+E, Ctrl+M, Ctrl+D, Ctrl+A, Ctrl+Z) matched, which
  does not prove that the rest do.
- Bryce 3D's DXF, 3DMF and OBJ import is taken from
  [period product information](https://discmaster.textfiles.com/view/27432/WPCDEC98.ISO/dxrs/softlib.cxt/00464_bryce%203d_productinfo.txt).
  Importing a file generated by this project has not been tried.
- Terrain Editor picture import is described for later versions on the
  [Daz forums](https://www.daz3d.com/forums/discussion/686971/terra-tropolis-bryce-daz-studio-poser).
